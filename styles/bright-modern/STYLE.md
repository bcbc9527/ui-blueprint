# bright-modern(明亮现代)

**气质**:干净、年轻、轻盈。白底,大留白,大号无衬线字,大图当主角,几乎没有装饰。适合人物主页、作品集、内容聚合、产品展示。

## 设计原则
1. **图片是主角,界面是白纸**:页面本身只有白、浅灰和墨色;色彩靠照片提供。
2. **一个强调色,只在一小块出现**:亮黄(`--color-primary`)只用于评分徽标和主按钮,上面永远放墨色文字,不用于大面积、不用于文字。
3. **大字当结构**:姓名/页面标题用超大字号、紧字距、粗字重;正文保持 16–17px、行高 1.7 以上、每行不超过 36 个汉字。
4. **圆角分层**:小件(按钮、胶囊)全圆;图片 14–20px;最外层容器(肖像、弹窗)28px。不要所有东西同一个圆角。
5. **留白代替分割线**:区块之间 `--space-8` 以上;只在列表行之间用 1px 浅灰线。
6. **动效只有一处**:进入页面时肖像与姓名的入场。其余交互只给焦点环和即时反馈,不做逐块淡入、不做悬停位移。

## 禁止
- 渐变背景、玻璃拟态、多个强调色。
- 黄色用于文字(对比度不足)。
- 全大写的标签、等宽字体的数据标签、`A · B · C` 式拼接元信息、按钮文字后面加“→”。
- 在 CSS 里写死颜色、字号、间距(必须用令牌)。

## 引用方式
```html
<link rel="stylesheet" href="../../../styles/bright-modern/tokens.css">
<link rel="stylesheet" href="../../../shared/base.css">
<link rel="stylesheet" href="../../../styles/bright-modern/components.css">
```

## 扩展令牌
`--space-9`、`--gutter`。
