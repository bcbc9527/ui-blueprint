# photo-dark(摄影暗色,500px 式)

**气质**:照片是唯一的主角。中性深灰的画布,界面退到最小,颜色全部由照片提供。适合摄影师主页、图库、作品集、相册。

## 设计原则
1. **界面只有灰阶**:背景、面、描边、文字都是纯灰,不带色偏。蓝色(`--color-primary` / `--color-link`)只用于“主操作”和“当前所在标签”。
2. **照片占满**:照片墙用**等高对齐的行式布局**,间距 4px,照片 2px 圆角;不做卡片边框、不加阴影。
3. **信息按需出现**:作品信息(标题、点赞)只在悬停/聚焦时从底部浮出;完整信息在灯箱里。
4. **大字用细字重**:页面标题、姓名用 Hanken Grotesk 的 300–500 字重,小字用 Noto Sans SC 400–500。
5. **参数用对照表**:拍摄参数是两列的名称/值表格,不用 `·` 拼成一行,不用等宽字体。
6. **动效只有一处**:封面图进入页面时淡入。其余交互只给即时反馈和焦点环。

## 禁止
- 彩色背景、渐变装饰、毛玻璃、多个强调色。
- 蓝色用于大面积块或大段文字。
- 全大写的标签、等宽字体的数据标签、按钮文字后面加“→”。
- 在 CSS 里写死颜色、字号、间距(必须用令牌)。
- 使用任何真实平台的名称、标识或真实相机品牌。
