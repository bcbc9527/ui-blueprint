# styles/ — 视觉风格库

每个子目录是一种独立的视觉风格,包含:

| 文件 | 作用 |
|---|---|
| `tokens.css` | 设计令牌(颜色、字体、间距、圆角、阴影…) |
| `components.css` | 该风格下的通用组件(按钮、卡片、导航…),只用令牌 |
| `STYLE.md` | 风格指南:气质、原则、禁止项、引用方式 |

**所有风格共用同一套令牌名称**(见 `_template/tokens.css`),因此同一份 HTML 结构换一个风格目录就能换皮。

新增风格:复制 `_template/` → 改名 → 修改令牌值与 `STYLE.md`。
