# contact-sheet(联系印样)

**气质**:摄影编辑在印样上选片的那一刻。灯箱白的页面,深绿黑的底片条,红色油性笔圈出要的、划掉不要的。适合影视、摄影、人物、档案类页面。

## 视觉语言:红色只属于“标记”
| 标记 | 含义 |
|---|---|
| 红圈 | 代表作 / 精选(这一项值得先看) |
| 红色角标(裁切线) | 当前或最近查看的这一项 |
| 红叉 | 不在当前筛选范围内 |

红色(`--color-mark`)**只**用于这三种手绘标记和肖像上的裁切线。按钮、链接、文字、图标一律不用红色。标记本身承载信息,不是装饰。

## 设计原则
1. **一个重点**:页面里唯一“大胆”的东西是油笔标记;其余保持安静、克制。
2. **底片只在该出现的地方出现**:片条(`--color-film`)承载作品画面;边码橙(`--color-edge`)只做片条边缘的印字。
3. **展示字用海报片头的字样**:特窄的 Archivo(拉丁)+ Noto Sans SC 黑体(中文),紧排、大字号;正文用 Noto Serif SC,行高 ≥ 1.9,每行不超过 36 个汉字。
4. **圆角像印刷品**:画面与按钮 2–4px,不做胶囊、不做统一大圆角卡片。
5. **深度靠明度,不靠阴影**:仅放大窗口使用 `--shadow-md`。
6. **动效只有两处**:进入页面时肖像“显影”;用户点击某一帧时角标画出。没有逐块淡入,没有悬停位移。

## 禁止
- 渐变背景、玻璃拟态、多个强调色。
- 红色用于按钮、链接或文字。
- 全大写的标签、等宽字体的数据标签、`A · B · C` 式拼接元信息、按钮文字后面加“→”。
- 在 CSS 里写死颜色、字号、间距(必须用令牌)。

## 引用方式

```html
<link rel="stylesheet" href="../../../shared/base.css">

```

`--color-film`、`--color-edge`、`--color-mark`、`--space-9`、`--gutter`、`--font-serif`。
