# 设计令牌(Design Tokens)

> 本仓库的每一个风格都由令牌定义。**示例页面里不允许出现颜色、长度、时长的字面量**——这样别人拿走一个示例,换一个风格目录就能换皮,改一个令牌就能全局调整。

## 一、三层结构

```
第 1 层  ref(原始值)      --ref-paper-50: #f5f6f5     调色板、间距/圆角/字号刻度。只有这一层写字面量
            ↓ 被引用
第 2 层  semantic(语义)   --color-bg: var(--ref-paper-50)   按“角色”命名。示例与组件只用这一层
            ↓ 被引用
第 3 层  component(组件)  --btn-radius: var(--radius-control)   在组件的作用域里声明,实例可局部覆盖
```

- **换风格**:改第 1 层的值和第 2 层的映射,示例不用动。
- **加新值**:先决定它属于哪一层。可复用的刻度进第 1 层;有“角色”含义的进第 2 层;只服务某个组件的留在该组件里。
- 文件位置:`styles/<风格>/tokens.css`(第 1、2 层)、`styles/<风格>/components.css`(第 3 层)。

## 二、命名约定
| 前缀 | 含义 | 例 |
|---|---|---|
| `--ref-*` | 原始值,**不要在示例里直接用** | `--ref-blue-600` |
| `--color-*` | 颜色角色 | `--color-text`、`--color-primary` |
| `--font-*` `--weight-*` `--leading-*` `--text-*` | 字体、字重、行高、字号 | `--text-lg` |
| `--space-*` | 间距刻度 | `--space-5` |
| `--gap-*` `--pad-*` | 间距的角色 | `--gap-aisle`、`--pad-card` |
| `--radius-*` | 圆角角色 | `--radius-control` |
| `--control-h-*` `--icon-*` `--avatar-*` | 尺寸 | `--control-h-md` |
| `--duration-*` `--ease` | 动效 | |
| `--z-*` | 层级 | |

**契约**:所有风格都必须定义 `styles/_template/tokens.css` 里的全部第 2 层名称,只改值。旧风格(早期创建)只保证旧契约。

## 三、圆角:什么时候用、用多少
圆角传达“这是什么东西”。同一类东西必须圆角一致,才会让人觉得它们是一类。

1. **按角色,不按大小**。先问“它是什么”(照片、控件、容器、浮层、标签、头像),再取对应令牌。不要凭感觉写 `6px`、`12px`。
2. **容器越大,圆角越大**,但有上限:控件 < 容器 < 浮层。最外层的浮层最圆。
3. **嵌套要同心**:内层圆角 = 外层圆角 − 内边距,不要内外一样大(会让角落显得“胖”)。公式:`max(var(--radius-media), calc(var(--外层圆角) - var(--内边距)))`。
4. **小元素的圆角不超过其高度的一半**。再大就是胶囊,用 `--radius-pill`。
5. **图片的圆角由内容类型决定**,不由容器大小决定:这个风格里照片永远是 `--radius-media`。
6. **同一屏里最多出现 3 种不同的圆角**(胶囊和圆形除外)。

## 四、间距:边界靠留白形成
- 同组内容:`--gap-stack`、`--gap-inline`
- 同级项目之间(如照片之间的“过道”):`--gap-aisle`
- 区块之间:`--gap-section`
- 容器内边距:`--pad-card`;页面两侧:`--pad-page`
- 能用间距分组就不要加线;必须加线时用 `--border-width` 和 `--color-border`。

## 五、图标
- 统一用 `shared/icons.js`,用法见该文件头部;样式 `shared/icons.css`。
- 图标是**该用就用**的工具:比文字更快更省地方时用(点赞、收藏、搜索、通知、导航、元信息),而不是为了装饰。
- 状态用填充或颜色变化表达,同一图标不换款。
- 仅图标的按钮必须有 `aria-label`。

## 六、自动检查
```bash
node scripts/check-tokens.mjs                 # 检查整个仓库
node scripts/check-tokens.mjs examples/xxx    # 只检查某个示例
node scripts/check-tokens.mjs --summary       # 只看每个文件的违规数
```
会报告:硬编码的颜色(`#fff`、`rgb()`、`white`…)、长度(`12px`、`1rem`、`2vw`…)、时长(`200ms`)。
- 媒体查询的条件里不能用变量,允许写字面量。
- `tokens.css` 是唯一允许写原始值的文件。
- 确需例外,在该行末尾写 `token-check-ignore` 注释并说明原因。

新增示例提交前必须通过检查。
